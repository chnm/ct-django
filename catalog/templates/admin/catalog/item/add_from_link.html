Which link to paste

IIIF manifest (best)
Many museums and libraries offer one, often behind a IIIF logo or a "manifest" link on the object page; the address usually ends in manifest.json or /manifest. It gives the image at any size, the title, a link to the object page and the holder's own rights statement.
IIIF image service
An address ending in info.json. Gives the image only.
The object's web page
If the page links to a IIIF manifest we use that; otherwise we use the page's preview image and title. Check it picked the right picture.
A direct image link
An address that opens just the picture (often ending .jpg). It carries no title or rights, so add the object's page as the record's source link afterwards.

What happens next

  • A private draft record opens for you to finish: title, summary, dates, places, people and terms, as for any record.
  • The image, thumbnail and manifest are stored as links, not copies. If the holder moves or removes the image, it will stop showing; the IIIF links are the most stable.
  • The record's rights statement is taken from the source when it states one. Otherwise it starts as: {{ default_rights }} Review it before publishing: records only show images publicly when they have a rights statement.
  • The public record page shows a "View at original location" link next to the image.
